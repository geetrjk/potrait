# Profile: RTX 3060 / 12GB VRAM Limit

**Target Architecture:** Low-overhead / Mid-tier cloud instances (e.g. SimplePod standard container).
**Total GPU Mem:** 12.288 GB

## Core Processing Rule: 100% FP8 Dependency

You **cannot** load the standard `FLUX.2-klein-9b-kv` Safetensors model (usually >16GB). Doing so will cause immediate CUDA OOM crashes when attempting latent image decoding. 

All checkpoints loaded when using this hardware profile strictly utilize INT8 or **FP8 precision layers.** 

### Mandatory VAE and CLIP Links

#### UNET (9.2 GB)
```bash
wget -O flux-2-klein-9b-kv-fp8.safetensors \
  'https://huggingface.co/black-forest-labs/FLUX.2-klein-9b-kv-fp8/resolve/main/flux-2-klein-9b-kv-fp8.safetensors'
```

#### CLIP / Text Encoders (8.1 GB)
*This is the precision-quantized split variant:*
```bash
wget -O qwen_3_8b_fp8mixed.safetensors \
  'https://huggingface.co/Comfy-Org/flux2-klein-9B/resolve/main/split_files/text_encoders/qwen_3_8b_fp8mixed.safetensors'
```

#### VAE (~320 MB)
```bash
wget -O flux2-vae.safetensors \
  'https://huggingface.co/Comfy-Org/flux2-dev/resolve/main/split_files/vae/flux2-vae.safetensors'
```

## System Start Overrides

Although `main.py` is configured, if running locally or adjusting start containers, ensure:
```bash
--lowvram --enable-manager --fp8_e4m3fn-text-enc --fp8_e4m3fn-unet
```
*SimplePod wraps execution natively; you might not have access to these args.*

## Max Resolution Cap

Do **not** use the Native Generation workflows locally above `1MP` (`1024x1024`). High-res structural manipulation *MUST* be piped into the `Module D: API Upscale` execution pathway (Nano Banana Pro) to offload the 4K rendering cost off the hardware.
