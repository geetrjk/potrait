# 01. Environment-Agnostic Setup Logic

> **Goal:** Track the universal ComfyUI configuration logic that works regardless of your cloud provider. Do **NOT** include hacks, VRAM patches, or parameter limits in this file.

## 1. Custom Node Ecosystem

These are the universally required repositories to run the Base Portrait Pipeline. The following URLs have been tested and verified functional.

| Node Repository          | Tested `git clone` URL | Known Quirks |
|--------------------------|-------------------------|--------------|
| **ComfyUI-RMBG**         | `https://github.com/1038lab/ComfyUI-RMBG.git` | Do *not* use AILab's vanity URL; it throws authentication dead-ends. Requires `pip install -r requirements.txt`. |
| **ComfyUI-Inpaint...**   | `https://github.com/lquesada/ComfyUI-Inpaint-CropAndStitch.git` | Lightweight logic, no heavy dependencies. |
| **rgthree-comfy**        | `https://github.com/rgthree/rgthree-comfy.git` | Handles the visual Image Comparer QA stage. |

| **ComfyUI-ReActor**      | `https://github.com/Gourieff/ComfyUI-ReActor.git` | Supports the ReActor-first identity preservation path. Requires `insightface` and `onnxruntime-gpu`; restart ComfyUI after install and verify ReActor node classes appear in `/object_info` before queueing ReActor workflows. |

## 2. Universal Dependency Execution

Regardless of OS, Pip requires the custom node extensions to be baked in.

```bash
cd <COMFY_ROOT>/custom_nodes/ComfyUI-RMBG
pip install -r requirements.txt

cd <COMFY_ROOT>/custom_nodes/ComfyUI-KJNodes
pip install -r requirements.txt

pip install insightface onnxruntime-gpu
cd <COMFY_ROOT>/custom_nodes/ComfyUI-ReActor
pip install -r requirements.txt

mkdir -p <COMFY_ROOT>/models/insightface
wget -c -O <COMFY_ROOT>/models/insightface/inswapper_128.onnx \
  'https://huggingface.co/datasets/Gourieff/ReActor/resolve/main/models/inswapper_128.onnx'
```

## 3. Workflow JSON Deployment Model

The core project operates on `.json` blueprints generated by the ComfyUI architect locally in Git, and transmitted structurally to the remote pod.

- **Source Target:** `production/workflows/*.json`
- **Destination:** `<COMFY_ROOT>/user/default/workflows/portrait_pipeline/`

Any system booting an instance MUST create that target structure, `scp`/`paramiko` the JSON files over, and execute a server reboot to force the Manager cache refresh.

### Manager API Restart Protocol
Every instance requires a `POST /auth` handshake to fetch a bearer token, prior to executing a `POST /manager/reboot`. Use universal `curl` over relying on OS-level `kill` commands natively on PID1.
